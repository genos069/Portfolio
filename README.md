## Customize

Update personal details in `src/lib/data.ts`. Star or unstar a public repository on GitHub to change the project cards; GitHub data is cached for up to one hour. The cards use each repository's description, primary language, topics, stars, forks, and homepage (if it is a valid web URL).

For project screenshots or short videos, add a file to `public/projects/` named after the repository, such as `public/projects/ClickNCart-.png` or `public/projects/genos069--ClickNCart-.webm`. Files directly in `public/` also work. Matching ignores case, spaces, hyphens, and underscores; a filename with the owner has priority when repository names overlap. Supported images: PNG, JPG, JPEG, WebP, AVIF, GIF, and SVG. Supported videos: MP4, WebM, and OGG. Without a matching file, the card shows a placeholder. Commit the media file to deploy it.
